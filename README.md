# SQL Server DBA Scripts

A practical Microsoft SQL Server administration portfolio covering database health, backup compliance, performance troubleshooting, blocking, storage, SQL Server Agent, and Always On Availability Groups.

## Areas Demonstrated
- Instance/database health checks
- Backup monitoring
- Blocking and session troubleshooting
- Database/file growth monitoring
- Index fragmentation analysis
- SQL Server Agent job monitoring
- Always On Availability Group health
- Performance incident investigation

## Repository Structure
- `health-checks/`
- `backup-recovery/`
- `performance/`
- `storage/`
- `always-on/`
- `sql-agent/`
- `docs/`

## Safety
These scripts are portfolio/lab examples. Review permissions, SQL Server version, environment standards, workload impact, and change-control requirements before production use. Read-only diagnostics are preferred by default; potentially disruptive maintenance should be tested and scheduled appropriately.
